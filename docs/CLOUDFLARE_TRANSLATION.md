# 在语音消息下查看译文

此修改版与单独部署的 Cloudflare 语音服务配合使用。先把服务部署好，再在扩展设置中选择“自定义”，填写服务提供的基础地址和密钥。地址应以 `/v1` 结尾，扩展会自动填写后续路径。

在“译文语言”中选择中文、英语、法语等语言并保存。打开 WhatsApp 网页版后，点击语音消息下的“转成文字”，再点击“翻译”。原文和译文会一起显示；译文可单独复制。已经转写的语音不需要再次上传音频。

切换译文语言后，点击“翻译”会生成新译文。扩展保留原文和最近一次译文，二者遵循同一条保留期限。

点击“翻译”时，扩展会把已识别的文字发送到你配置的服务；不会再次发送语音。

此版本需要作为本地扩展安装。安装前请停用商店版本，避免同一条语音出现两组按钮。两个版本各自保存设置和转写记录，浏览器不会自动迁移商店版本的缓存。
